# sccap

Windows 11 用のシンプルなスクリーンキャプチャーツールです。起動するとその瞬間の画面が静止表示され、範囲またはウインドウを選ぶと PNG で保存して終了します（常駐しません）。

## 動作環境

- Windows 10 / 11 (x64)
- [.NET 8 デスクトップランタイム](https://dotnet.microsoft.com/download/dotnet/8.0)

## 使い方

`dist\sccap.exe` を起動します。

| 引数           | 動作                                |
| -------------- | ----------------------------------- |
| (なし)         | 設定ファイルの `defaultMode` で開始 |
| `region` / `r` | 範囲モードで開始                    |
| `window` / `w` | ウインドウモードで開始              |

### 範囲モード

- 1点目をクリックし、続けて2点目をクリックすると、その2点を対角とする矩形を保存します（両端のピクセルを含みます）
- ドラッグでも指定できます
- 細かい位置合わせ用に、カーソル付近に拡大鏡と座標を表示します
- 矢印キーでカーソルを 1px（Shift を押しながらで 10px）動かせます。Enter キーはクリックと同じ扱いです
- 右クリックで1点目を取り消します

### ウインドウモード

- マウスを乗せたウインドウが強調表示され、クリックするとそのウインドウを保存します

### 共通

- Tab（または Space）キーで範囲モードとウインドウモードを切り替えます
- Esc キーで何も保存せずに終了します

### ホットキーで起動するには

`sccap.exe` のショートカットを「スタートメニュー」または「デスクトップ」に作り、プロパティの「ショートカット キー」に `Ctrl + Alt + S` などを設定してください。ウインドウモード用のショートカットも作れます（リンク先の末尾に ` window` を追加）。

## 設定ファイル

`sccap.exe` と同じフォルダにある `sccap.json` で設定します（ファイルが無い場合は初回起動時に既定値で作成されます）。`//` コメントも書けます。

| キー                  | 既定値                    | 説明                                                                                                                                                                 |
| --------------------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `saveDirectory`       | `{MyPictures}\\sccap`     | 保存先フォルダ。`%USERPROFILE%` などの環境変数や、`{MyPictures}` `{Desktop}` `{MyDocuments}` などの特殊フォルダ名が使えます。相対パスは exe のあるフォルダが基準です |
| `fileNameFormat`      | `sccap_{yyyyMMdd_HHmmss}` | ファイル名（`.png` は自動付与）。`{ }` の中は日時の書式です。同名のファイルがあれば `_1`, `_2` … を付けます                                                          |
| `defaultMode`         | `region`                  | 引数なしで起動したときのモード（`region` / `window`）                                                                                                                |
| `windowCaptureMethod` | `screen`                  | `screen`: 画面に見えている通りに切り出します。`printWindow`: ウインドウ自身に描画させるので背後に隠れた部分も撮れますが、一部のアプリでは黒くなることがあります      |
| `copyToClipboard`     | `false`                   | 保存した画像をクリップボードにもコピーします                                                                                                                         |
| `openAfterSave`       | `false`                   | 保存後に既定のアプリで画像を開きます                                                                                                                                 |
| `showNotification`    | `true`                    | 保存後に画面右下へ通知を表示します（クリックするとエクスプローラーで表示します）                                                                                     |

## ビルド

.NET 8 以降の SDK が必要です。

```powershell
dotnet publish sccap.csproj -c Release -o dist
```

## 仕組みと注意点

- 起動した瞬間に全モニターをまとめて撮影し、その静止画の上で選択します。そのため、動画やメニューなども起動した時点の状態で保存されます
- 高 DPI（拡大率 125% / 150% など）や複数モニターでも、物理ピクセル単位で正しく保存します
- 保護されたコンテンツ（DRM のかかった動画など）は黒く写ることがあります
